# Documentation

Reference docs for the football data pipeline. The top-level
[README](../README.md) is the overview and [CONTRIBUTING.md](../CONTRIBUTING.md)
covers making a change.

## Contents

1. [Architecture](architecture.md): layers, data flow, the warehouse, where state lives.
2. [Running the project](running-the-project.md): setup, commands, rebuilds, troubleshooting.
3. [Ingestion](ingestion.md): the Python layer, the raw schema, the run log, CLI reference.
4. [Data model](data-model.md): the star schema, the ERD, and how `fact_standings` is built.
5. [Data dictionary](data-dictionary.md): every table and column, with types.
6. [Testing and quality](testing-and-quality.md): each test layer and what it catches.
7. [Orchestration](orchestration.md): the CI and scheduled pipeline workflows.
8. [Design decisions](design-decisions.md): the decisions, their reasons, and the known limitations.
9. [Exports](exports.md): the Parquet export and guidance for a Power BI model.

## Diagrams

`lineage_dag.svg` and `erd.svg` are generated by `generate_diagrams.py` from
dbt's manifest. CI regenerates them and fails if the committed files differ.
To rebuild them locally:

```bash
cd dbt && dbt parse --profiles-dir . && cd ..
python docs/generate_diagrams.py
```
